# Fermi

Fermi is a systems-oriented language project focused on safe memory handling, explicit ownership, and high-performance backend and runtime development.

This repository is currently under active development. The implementation, documentation, and public-facing project materials are being refined and will be expanded as the language and tooling mature.

For current project context, see:

- [docs/README.md](docs/README.md)
- [docs/PLAN.md](docs/PLAN.md)

This README is intentionally kept minimal while the project structure and documentation are being finalized.
